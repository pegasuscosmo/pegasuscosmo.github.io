Barnes–Hut N-Body Simulator

Python · Taichi (GPU) · Parallel Algorithms

Simulates gravity between up to 2,000,000 particles in real time by building a binary radix tree entirely on the GPU each frame — encoding positions as Morton codes, sorting them with a custom parallel radix sort, and deriving the Barnes-Hut tree structure directly from the sorted codes. Includes density, velocity, and hybrid visualization modes.

Planetary Ring Simulations

Python · Taichi (GPU) · Orbital Mechanics

A series of simulators modeling how moons gravitationally sculpt planetary rings, with interactive body creation, time-warp, and trajectory drawing. The latest version models Saturn's rings using Wisdom–Holman symplectic integration (propagating Kepler orbits with Lagrange coefficients) for long-term orbital stability, plus statistical particle-particle collisions.

Black Hole Renderer

Python · Ray Tracing · Relativistic Physics

A from-scratch ray tracer that bends light around a black hole using a = pos·(3M·h²)/r⁵ instead of Newtonian gravity, rendering a textured accretion disk. Exports separate layers — event horizon, full render, and luminosity masks — for compositing.
